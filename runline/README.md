## 브라우저에서 실행하기

Flutter SDK와 Chrome이 설치되어 있는지 확인한 뒤, Flutter 앱 폴더(`runline/`, `pubspec.yaml`이 있는 폴더)에서 다음 명령을 실행합니다.

```bash
flutter run -d chrome
```
