# runline


## App1: Flutter 지도·GPS 러닝

담당 영역은 Flutter 앱의 지도, 그림 기반 코스 추천 연결, GPS 러닝 및 로컬 기록이다. 이 브랜치는 기존 App1 작업에 완성 사본의 기능을 추가하며 main을 병합하지 않는다.

| 기능 | 구현 내용 |
| --- | --- |
| 카카오맵 | Android/Web 지도, 현재 위치 마커, 위치 추적·카메라 재중심, 코스·이동 궤적 표시 |
| 그림 입력 | **지도와 분리된 캔버스**에서 자유 그림 및 별·하트·초승달 프리셋 입력 |
| 코스 추천 | 서버 v1 API 상태 확인·그림 전송, 실제 OSM 추천 후보 조회·선택 |
| GPS 러닝 | 자유 러닝·추천 코스 러닝, 거리·활동 시간·평균 페이스, 일시정지·재개·종료 |
| 코스 진행 | 확인된 통과 구간을 초록색으로 표시, 진행률·남은 거리, 이탈·복귀 감지 |
| 기록 | 로컬 체크포인트 저장·미완료 세션 복구, 홈의 기록 목록·종료 후 상세·저장 궤적 조회 |

그림을 실제 지도 위에 직접 그리거나 도로를 편집하는 기능은 없다. 다음 구간 방향 표시는 교차로별 좌·우회전 안내가 아니며, 백그라운드 GPS·음성 안내·자동 재탐색·서버 기록 동기화는 구현하지 않았다. 활동 탭 UI는 이 작업에서 구현하지 않았다.

실제 기기 GPS, 카카오 지도 인증·렌더링, 실제 추천 서버와의 전체 흐름은 미검증이다. 빌드·대역 기반 자동 테스트 통과와 구분한다.

실행·설정·검증 결과와 제한 사항은 [Flutter App1 README](runline/README.md)를 참고한다.
